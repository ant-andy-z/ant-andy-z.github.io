This is a personal blog hosted on GitHub Pages. Each post is a Markdown file in `src/content/blog/`. The homepage lists published posts; drafts stay off the site until you set `draft: false` (or omit `draft`).

To write the next one:

1. Add a new `.md` file next to this one.
2. Fill in `title`, `description`, and `pubDate` in the frontmatter.
3. Write in Markdown. Math works too — see the LaTeX demo post.

The live site updates when `main` is pushed and GitHub Actions finishes the build.
